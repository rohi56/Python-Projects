# Python Project for Data Science – IBM

## Project Overview
This repository contains my completed assignments and project work for the **IBM Python Project for Data Science** course.  
The project demonstrates practical data science skills including:

- Extracting stock market data using APIs and Python libraries
- Web scraping financial information from websites
- Data cleaning and preprocessing
- Data visualization and dashboard creation
- Working with Jupyter Notebooks for analysis

The project focuses on analyzing stock and revenue data for companies such as **Tesla (TSLA)** and **GameStop (GME)**.

---

## Project Objectives
The main objectives of this project were to:

- Use the `yfinance` library to extract stock market data
- Perform web scraping using `BeautifulSoup`
- Clean and organize extracted datasets using `pandas`
- Visualize stock prices and revenue trends
- Build interactive graphs for business analysis
- Apply Python programming concepts in real-world data science tasks

## Key Tasks Completed

### 1. Extracting Stock Data Using Python Library
- Used the `yfinance` library to collect stock information
- Retrieved historical stock data
- Worked with Tesla and GameStop stock datasets

### 2. Web Scraping Financial Data
- Extracted revenue data from web pages
- Parsed HTML tables using BeautifulSoup
- Converted scraped data into structured DataFrames

### 3. Data Cleaning & Preparation
- Removed unnecessary symbols and formatting
- Converted values into numerical formats
- Organized datasets for analysis

### 4. Data Visualization
- Created graphs showing stock trends
- Compared revenue growth and stock performance
- Built dashboard-style visualizations using Plotly and Matplotlib

## How to Run the Project

### 1. Clone the Repository
```bash
git clone <repository-url>
```

### 2. Install Required Libraries
```bash
pip install pandas yfinance requests bs4 html5lib lxml matplotlib plotly
```

### 3. Open Jupyter Notebook
```bash
jupyter notebook
```

### 4. Run the Notebooks
Open and execute the notebooks sequentially.
