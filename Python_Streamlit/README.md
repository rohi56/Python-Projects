# 🐍 Python Streamlit Examples — Learn Streamlit Widgets & UI Components

A hands-on collection of **Python Streamlit code examples** covering every core widget and UI element in the [Streamlit](https://streamlit.io/) framework — buttons, forms, sliders, tabs, columns, sidebars, file uploaders, and more. Perfect for beginners learning **Streamlit for Python web apps**, data dashboards, and interactive data science tools.

## 📖 About This Project

This repository is a **Streamlit tutorial / practice project** built to demonstrate how to create interactive web apps and dashboards using only Python — no HTML, CSS, or JavaScript required. Each script is a self-contained, runnable example showing how a specific Streamlit widget or layout component works, making it a great **reference guide for learning Streamlit from scratch**.

Whether you're a student, data analyst, or Python developer exploring **rapid web app development**, this repo walks through the essential building blocks of a modern Streamlit application.

## 📦 Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/<your-username>/Python_Streamlit.git
cd Python_Streamlit
pip install streamlit pandas
```

---

## ▶️ Usage

Run any example script directly with Streamlit:

```bash
streamlit run button_widget.py
```

Replace `button_widget.py` with the name of any file in the repository to explore that specific widget or feature. For example:

```bash
streamlit run st_tabs.py
streamlit run create_a_form.py
streamlit run multiple_pages.py
```

The app will open automatically in your default browser at `http://localhost:8501`.
